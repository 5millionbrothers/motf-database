# 운영 안정화 확인표

## 데이터베이스

- [ ] 운영 DB 백업 후 `57`, `58`, `59`를 순서대로 한 번씩 실행했다.
- [ ] 일반 이용자가 다른 회원의 예약·주문·포인트·내 MT를 읽지 못한다.
- [ ] 초대 회원은 내 MT를 볼 수 있지만 수정하지 못한다.
- [ ] 이벤트 구글폼 URL은 신청 시작 전 일반 API에서 보이지 않는다.
- [ ] 관리자만 포인트·쿠폰·수수료·노출 순서·이벤트를 변경할 수 있다.

## Toss Payments

- [ ] 이용자 Vercel에 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`, `TOSS_ENABLED_METHODS`를 등록했다.
- [ ] 사장님 Vercel에 서버 전용 `TOSS_SECRET_KEY`를 등록했다.
- [ ] Toss 웹훅 URL을 `https://motf.co.kr/api/toss-webhook`으로 등록했다.
- [ ] 카드와 계좌이체 성공·취소·실패를 각각 테스트했다.
- [ ] 성공 URL 새로고침과 웹훅 재전송에도 예약·주문이 한 번만 생긴다.
- [ ] 브라우저에서 금액을 바꿔도 서버가 DB 금액 불일치로 거절한다.
- [ ] 15분 안에 결제하지 않으면 객실과 상품 선점이 해제된다.
- [ ] 숙소 결제에는 객실 기본금만 포함되고 추가 인원·부대시설은 현장 결제로 안내된다.
- [ ] 사장님 거절은 Toss 취소가 성공한 뒤 예약 거절·포인트 복구·방막기 해제가 반영된다.
- [ ] 기간별 부분환불 뒤 남은 취소수수료가 사장님 정산에 반영된다.
- [ ] 가상계좌는 계약 승인 전 `TOSS_ENABLED_METHODS`에 넣지 않았다.

## 본인확인과 회원

- [ ] `IDENTITY_HASH_PEPPER`는 길고 무작위인 운영값이며 외부에 공개되지 않았다.
- [ ] KCP 어댑터가 이름·휴대전화·생년월일·CI·DI를 서버 간 통신으로 반환한다.
- [ ] 이메일과 사장님 가입 모두 KCP 인증 후에만 완료된다.
- [ ] 카카오 가입 회원도 최초 1회 KCP 인증과 서비스 비밀번호·소속 입력을 완료한다.
- [ ] 비밀번호 찾기는 가입 이메일과 동일한 CI일 때만 새 비밀번호를 설정한다.
- [ ] 탈퇴 후 개인정보 익명화와 소셜 연결 해제가 정상 동작한다.
- [ ] 미성년 계정은 주류 상품을 주문할 수 없다.

## 사업자와 지도

- [ ] 사장님 Vercel에 국세청 `DATA_GO_KR_SERVICE_KEY`를 등록했다.
- [ ] 사업자번호·개업일자·대표자명 진위와 계속사업 상태가 모두 확인된다.
- [ ] 숙박업 신고증, 정산계좌 등 추가 서류를 운영자가 검토한다.
- [ ] 주소 검색 후 좌표 저장과 이용자 지도 마커를 확인했다.

## 포인트·쿠폰·정산

- [ ] 포인트·쿠폰 사용액은 moTF 부담 할인으로 기록된다.
- [ ] 사장님 정산은 할인 전 판매가에서 계약 수수료만 공제한다.
- [ ] 100만원 판매가에 5만P 사용 시 고객 외부결제는 95만원, 수수료 3%라면 사장님 정산은 97만원이다.
- [ ] 포인트 잔액이 음수가 되거나 같은 캐시백이 두 번 지급되지 않는다.
- [ ] 할인코드 기간·전체 한도·개인 한도·최대 할인액이 적용된다.

## 운영 콘텐츠

- [ ] 운영자가 카드뉴스, 팝업, Instagram 링크, 레크레이션을 등록·숨김 처리할 수 있다.
- [ ] 이벤트가 설정 시각 전 `곧 신청`, 진행 중 `신청`, 이후 `마감` 또는 `종료`로 보인다.
- [ ] 커뮤니티 게시글과 리뷰의 공개 상태를 운영자가 관리할 수 있다.
- [ ] 빠지와 스키는 클릭되지 않는 Coming Soon 상태다.

## 장애 대응

- [ ] Toss·KCP·Supabase 오류 시 요청 시각, 주문번호, 사용자 ID, API 응답 코드를 기록한다.
- [ ] 결제 취소는 성공했지만 DB 반영이 실패한 건을 찾는 운영 점검 절차가 있다.
- [ ] 테스트 키와 운영 키를 같은 Vercel 환경에 섞지 않는다.
- [ ] 운영 키 전환 전 법률·세무·PG 약관 검토를 완료한다.
