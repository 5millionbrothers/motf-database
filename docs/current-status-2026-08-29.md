- 휴대폰 본인확인: KCP 계약용 서버 어댑터

## 이번 마이그레이션

- `57_toss_identity_points_foundation.sql`: Toss 결제, KCP 본인확인 원장, 사업자 서류, 포인트·쿠폰, 기본금 결제, 정산 재원
- `58_events_content_mt_collaboration.sql`: 모티프 주최 MT, 카드뉴스·팝업·레크레이션, 내 MT 보기 전용 초대와 투표 기반

## 출시 전 외부 계약 필요

- Toss 운영 키와 사용 결제수단 승인
- KCP 휴대폰 본인확인 계약 및 `KCP_CERT_ADAPTER_URL` 구현
- 공공데이터포털 국세청 API 활용 신청
- 운영 약관·개인정보처리방침·취소 규정 법률 검토

## 구현된 운영 기능

- 카드·계좌이체 중심 Toss 결제와 향후 가상계좌 확장
- 객실 기본금만 온라인 결제, 추가금 현장 직접 결제
- 포인트·할인코드·캐시백 캠페인과 할인 전 판매가 정산
- 예약 거절 자동 전액환불, 이용자 기간별 부분환불
- 회원 포인트, 수수료, 업장 노출, 이벤트, 카드뉴스, 팝업, 레크레이션 관리
- 행사 신청 시간 전 구글폼 링크 비공개
- 내 MT 소유자 편집과 초대 회원 보기 전용 참여
- 방 사진 전용 갤러리와 확대 보기

## 아직 운영자가 해야 하는 일

1. Vercel 환경변수를 두 프로젝트에 등록한다.
2. Supabase SQL Editor에서 신규 마이그레이션을 순서대로 실행한다.
3. Toss와 KCP 테스트 계약값을 넣고 샌드박스 시나리오를 확인한다.
4. 국세청 서비스키를 사장님 Vercel 프로젝트에 넣는다.
5. 운영자 화면에서 실제 수수료율, 포인트 캠페인, Instagram 주소와 첫 이벤트를 등록한다.
6. 운영 키 전환 전에 결제·환불·중복 웹훅·권한 분리 회귀 테스트를 완료한다.
